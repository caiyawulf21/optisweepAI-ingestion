Summary

Use the MDI Support chat sort confirmation table to inspect package-level SortConf records and determine whether the affected source matches the source-described AIO one pattern: rows associated with Al01Chat show Width, Height, and Weight as 1, with MissingDimensionData visible in the same view. This procedure supports a support-side conclusion that AIO one is not sending sort data or dimension data; it does not establish a deeper root cause.

When To Use

Use when site or support reports overflowing, suspected missing dimension data, or suspected missing sort data, and you need to verify from the live sort confirmation support table whether Al01Chat/AIO one records match the pattern shown in the source: SortConf rows with Width, Height, and Weight all equal to 1.

Procedure Steps

Step 1 — Open the sort confirmation support table with package and dimension columns visible

Responsible role: L1_support

Instruction:

Open the live MDI Support chat support table used for lane activity review and confirm the table shows the package-level columns visible in the source, including Zone, LaneName, PackageUid, TrackingNumber, Length, Width, Height, Weight, Cube, ToteId, Message, PackageClassification, MissingDimensionData, MissingInduct, ToteNotfound, Diverted, OffTheEnd, and Recirc.

Expected result:

The live table is open and the named columns are visible for package-level records.

Screens / Images:

Stop or Escalate If:

  • The live support view cannot be opened.
  • The required columns are not available in the live view.
  • There is no visible field that can be used to correlate rows to Al01Chat or AIO one.

Step 2 — Filter the live table to sort confirmation records

Responsible role: L1_support

Instruction:

Apply a filter on the Message column so the live table shows only sort confirmation records (SortConf / sort confirmation) as described in the source.

Expected result:

The table is filtered to SortConf rows only.

Screens / Images:

Stop or Escalate If:

  • The Message column is not available for filtering.
  • The live view does not support filtering to sort confirmation records.

Step 3 — Identify rows associated with Al01Chat or the affected source

Responsible role: L1_support

Instruction:

Within the filtered SortConf rows, inspect the package-level identifiers and locate rows associated with the affected source. Use the visible row values shown in the source, including PackageUid entries ending in Al01Chat, to correlate the records to AIO one.

Expected result:

A set of SortConf rows associated with Al01Chat / AIO one is identified for review.

Screens / Images:

Stop or Escalate If:

  • The live rows cannot be correlated to Al01Chat or AIO one.
  • The available fields do not support source attribution.

Step 4 — Inspect Width, Height, Weight, and MissingDimensionData across the Al01Chat SortConf rows

Responsible role: L1_support

Instruction:

Review the Al01Chat SortConf rows and compare the dimension-related fields across those rows. Check whether Width, Height, and Weight repeat as 1 across the affected rows, and review the MissingDimensionData field in the same rows.

Expected result:

You can determine whether the live Al01Chat SortConf rows match the source-described pattern of Width, Height, and Weight all being 1, with MissingDimensionData visible in the same table.

Screens / Images:

Stop or Escalate If:

  • The dimension fields do not match the source-described pattern but the upstream issue is still suspected.
  • The live rows are too limited or inconsistent to determine whether the pattern is present.

Step 5 — Conclude and communicate the support finding without extending root cause

Responsible role: L1_support

Instruction:

If the live SortConf view matches the source-described evidence pattern for Al01Chat, record and communicate that AIO one appears not to be sending sort data or dimension data based on the live table evidence. If the pattern does not match, do not make that conclusion from this procedure alone.

Expected result:

The support finding is limited to what is observable in the live SortConf table: either the Al01Chat rows match the missing sort or dimension data pattern, or they do not.

Screens / Images:

Stop or Escalate If:

  • AIO one cannot be correlated in the live view from the available fields.
  • The dimension values do not match the source-described pattern but the upstream data issue is still suspected.
  • Additional root cause analysis or corrective action is requested beyond the live table evidence.
